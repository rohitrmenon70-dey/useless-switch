Arduino based project that does absolutely nothing useful but has plenty of attitude.
When you flip the switch ON, the machine uses a motor powered mechanism to turn the switch OFF again. The Arduino detects the switch position and controls the motor to push it back, making it look like the machine is refusing to let you turn it on.

We just thought about why not another arm OFF the switch whenever we turn ON...

We placed a servo motor with an arm connected to Arduino nano. Whenever the switch is in ON position it detects that and the servo motor turn it OFF...
